# avaliacaoWeb-25-10
Avaliação aula Web I - BoodStrep

Nesta avaliação criamos um site simples para a floricultura "FLORES E VINHO TINTO".

Para desenvolver o layout do site, foi usada a IDE VS Code para escrever o documeno html, css e BoodStrep.

*Os elemenos usados foram:* 

Navbar com logo, nome da loja, botões de destaque e preços. (Ambos sem funcionalidade no momento)
Em seguida criei um carroseu, com 3 imagens do ilustrativas que codam automaticamente
Paragrafo com texto "Descrição"
Carrocel de serviços (buquê de casamento, arranjos de flores para eventos e cesta do amor) com descrição e valores.
Rodapé com logo, telefone para contato, dados da empresa como CNPJ e endereço.
